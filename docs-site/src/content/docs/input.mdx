<Example title="Input" source={source}><InputDemo client:only="vue" /></Example>

## Usage

```vue
<NbInput v-model="name" label="Name" placeholder="Ada Lovelace" />
```

Pass `hint` for supporting text or `error` for validation feedback. Native attributes such as `required`, `name`, `autocomplete`, and `disabled` are forwarded to the input.
