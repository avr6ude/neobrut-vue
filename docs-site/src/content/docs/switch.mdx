Use `NbSwitch` for settings that turn on or off. It requires a visible `label` and binds with `v-model`.

## Preview

<Example title="Switch" source={source}><SwitchDemo client:only="vue" /></Example>

## Usage

```vue
<NbSwitch v-model="alerts" label="Launch alerts" />
```

The underlying checkbox keeps its native keyboard and form behavior. Use `NbCheckbox` for selecting an option in a group or agreeing to a statement.
