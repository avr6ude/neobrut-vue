Control `NbDialog` with `v-model:open` and provide a `title` so the dialog has an accessible name.

## Preview

Open the dialog, press Tab to move through its controls, then Escape to close it.

<Example title="Dialog" source={source}><DialogDemo client:only="vue" /></Example>

## Usage

```vue
<NbButton @click="open = true">Open dialog</NbButton>
<NbDialog v-model:open="open" title="Ready to go?">
  Dialog content.
</NbDialog>
```

`NbDialog` restores focus to the previously active element when it closes.
