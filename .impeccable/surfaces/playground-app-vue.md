# Landing surface

Mode: Persuade. Audience: Vue developers evaluating a colorful component library. Primary action: install the package; secondary actions: browse documentation and use the gallery. Proof: real interactive components from the published package. Preserve all existing gallery interactions and the library's visual identity.

## Direction contract

THESIS: The interface itself is the pitch; refuse a generic marketing hero followed by feature cards.

OWN-WORLD: Use the library's saturated yellow, mint and coral with black 3px strokes, offset shadows, rounded geometry, and sturdy rounded display type. The elements are components, not illustrations of components.

STORY: A developer sees the kit working, finds the install command, then moves to docs or explores the complete component gallery.

FIRST VIEWPORT: A narrow site masthead gives way to an asymmetric yellow introduction: huge two-line promise and install action on the left, a large live component composition on the right. The lower edge makes the gallery's breadth visible without cramming it into the hero.

FORM: Existing-surface extension, not a new visual identity; no concept seed. The signature interaction is the live preview's form state, which visibly changes without leaving the page.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
