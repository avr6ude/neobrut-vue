# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Vue 3 developers choosing and using components for colorful application interfaces.

## Product Purpose

`@neobrut-vue/core` provides reusable neo-brutalist Vue components. The landing helps developers evaluate the kit; the documentation helps them install it and use the published API.

## Operating Context

The package is installed from npm in a client-side Vue 3 app. Users import the stylesheet and named components. The repository's playground demonstrates the components interactively.

## Capabilities and Constraints

- Published package version at this site's initial build: 0.5.0.
- Requires Vue 3.5 or newer and a client-side Vue application; no request-time SSR service for the sites.
- The landing and documentation live together at `neobrut.avrdu.de` and `neobrut.avrdu.de/docs/`.
- Playwright documentation is out of scope.

## Brand Commitments

The package name is `@neobrut-vue/core`. The user chose colorful neo-brutalism and cited neobrutalism.dev as a reference. The existing package tokens and components are the landing's primary visual material.

## Evidence on Hand

`README.md` contains installation and usage examples. `playground/` contains working interactive examples. `tests/` covers component behavior and accessibility. No testimonials or adoption claims are available and none should be invented.

## Product Principles

- Show real components and behavior before making claims about them.
- Make installation and finding a component fast.
- Preserve semantic HTML, keyboard access, and explicit ARIA relationships.
- Keep library documentation on the library's own site, independent of the personal homepage.

## Accessibility & Inclusion

Component semantics, keyboard operation, visible focus, and appropriate ARIA are part of the kit's stated quality bar.
